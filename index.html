Using the signatures

Click Copy formatted signature and paste into Outlook → Settings → Accounts → Signatures (or Mail → Compose and reply, depending on version). Save and send a test email to yourself.

For an alternative approach, use an accompanying Word file from the full package, replace the bracketed fields, copy the signature from Word, and paste it into Outlook. Browser clipboard support varies and the hosted images must be publicly accessible for recipients to see them.

The provided CommNS artwork is extracted from the supplied reference image. For production, replace it with the approved high-resolution logo from your UW–Madison communications team. Links and optional fields should be verified by each team member.
